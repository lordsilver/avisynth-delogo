# AviSynth Delogo Sources

This archive contains the exact upstream inputs used to build the matching AviSynth Delogo Windows x64 release.

Every file under `assets` is unchanged from its recorded upstream source and was verified against `toolchain.lock.json` before this archive was created. This includes the pinned `InpaintDelogo.avsi` and `DoomDelogo.avsi` sources as well as all upstream archives and packages. `sources.yaml` records the selected versions and upstream comparison, while `THIRD-PARTY-NOTICES.md` summarizes the applicable third-party terms.

FrameSel and RT_Stats are preserved from the author archive URLs linked by the AviSynth Wiki through the Internet Archive because no newer official build was found.
